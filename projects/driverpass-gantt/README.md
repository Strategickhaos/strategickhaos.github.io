# DriverPass Gantt Laboratory — SAGCO WEB REV001

[Live interactive website](https://strategickhaos.github.io/projects/driverpass-gantt/) · [Editable Lucidchart REV004](https://lucid.app/lucidchart/f4c7231e-6f78-4b32-979b-8c4c8e9464ad/view) *(Lucid document access may require permission)*

A standalone, accessible-first GitHub Pages case-study webpage presenting the **12 source-listed DriverPass project tasks** with their start/end dates. This is an educational planning visualization, **not a report of a built or deployed DriverPass system**.

## Evidence boundary

- **FACT:** Task names, start/end dates, and order follow *Southern New Hampshire University, CS 255 DriverPass Interview Transcript*, Schedule Planning, pp. 5–6.
- **VISUAL INTERPRETATION:** Four workstream colors are analyst-created groupings for readability, not source-labeled critical-path dependencies.
- **UNKNOWN:** The source provides no calendar year or verified completion status. Shared handoff dates and overlapping periods are preserved.
- **CALENDAR NOTE:** A non-leap calendar is used *only* for proportional positions in the page; no actual project year is asserted.

## Features

- Native HTML task table with visible date ranges and timeline bars
- Keyboard-focusable task details and filter controls
- Keyword search, workstream filters, and CSV export
- Landscape print stylesheet for a clean printable view
- No external JavaScript libraries, tracking, credentials, or private invitation tokens
- Link to the editable Lucidchart source document

## Maintaining the schedule

Edit the `TASKS` constant in `index.html`. Keep the original source dates unchanged unless revising against a new, directly verified source. Test visually after each revision and retain revision identifiers.
